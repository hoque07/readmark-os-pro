# Changelog

## 2.0.0 - 2026-07-30

- Rebuilt as a production-structured React and FastAPI monorepo.
- Added SQLite local storage and PostgreSQL production compatibility.
- Added JWT owner authentication with secure password hashing.
- Added AI generation through the OpenAI Responses API with offline fallback.
- Added editable generated drafts, publishing, drafts, cover uploads and CRUD.
- Added reading progress, statistics, spaced review scheduling and PWA support.
- Added Windows one-click setup/start scripts, Docker, Render and GitHub workflows.
- Added seeded demo content and full documentation.
- Added owner Settings & Data workspace, JSON export and in-app password change.
- Replaced decorative reading bars with real 30-day post activity data.
- Added GitHub Pages repository-path and HashRouter deployment support.
- Isolated the test suite in a disposable database so validation never modifies local user data.
